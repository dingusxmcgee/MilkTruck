# MilkTruck
 
 The Milk Truck is a dairy-inspired numpad-having minivan-adjacent keyboard. Featuring an integrated design and the choice of either an OLED or RGB LEDs underneath the patented Milk Blocker™️

 ![CaseImage](https://github.com/dingusxmcgee/MilkTruck/blob/main/Images/CaseImage.jpg?raw=true)
 
 This case design uses an optional acrylic bottom and 3d printable feet to increase the angle of the case from 0 to 5 degrees.
